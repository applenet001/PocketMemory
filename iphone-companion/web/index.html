从 iPhone 分享到 PocketMemory

  
用 iPhone 打开此页以获取接收地址。分享时，手机和运行 PocketMemory 的电脑须连接同一可信 Wi-Fi。

  
  
  
用同一条快捷指令分享图片、链接或文字

  
    
    
  1. 新建「存到 PocketMemory」。点编辑器底部的 ⓘ，打开「在共享表单中显示」。回到顶部「接收」，勾选 URL、文本、图像、PDF 和文件。
    2. 
    
  2. 添加「Base64 编码」，动作选「编码」，输入选「快捷指令输入」。
    3. 
    
  3. 添加一张「获取 URL 内容」卡片，地址填上方接收地址，方法选 POST。标头名填 Authorization，值填 Bearer 你的个人访问密钥，保留中间的空格。
    4. 
    
  4. 请求体选「JSON」，添加文本字段 shared_base64，值选「Base64 编码」输出。可添加「显示结果」，输入选「URL 的内容」。
    5. 
    
  5. 每次分享一项。先从截图预览分享一张图，再从 Safari 分享一个链接，到「记忆库」确认。分享文件时，另加 JSON 字段 name 可传入原文件名。
    6. 
  

  

  单独配置照片、文件或链接的上传方式
  
单张照片或截图

  
  
  
    
    
  1. 新建「存图片到 PocketMemory」。在编辑器底部点 ⓘ，开启「在共享表单中显示」，接收类型选择图像。
    2. 
    
  2. 添加「获取 URL 内容」，填图片接收地址，方法选 POST。添加标头 Authorization，值填 Bearer 你的个人访问密钥，中间保留一个空格。
    3. 
    
  3. 请求体选「文件」，值选「快捷指令输入」。添加「显示结果」，输入选「URL 的内容」。
    4. 
    
  4. 在截图预览或「照片」里打开一张图，点「分享」，选「存图片到 PocketMemory」。
    5. 
  

  
PDF、其他文件或多张照片

  
    
    
  1. 在 iPhone 的「快捷指令」中新增「存到 PocketMemory」。打开快捷指令详情里的「在共享表单中显示」，接收类型选择图像、PDF 和文件。
    2. 
    
  2. 添加「重复每一项」，输入选「快捷指令输入」。把「获取 URL 内容」放在循环里，填上方接收地址，再把方法设为 POST。
    3. 
    
  3. 添加标头 Authorization，值填 Bearer 你的个人访问密钥，中间保留一个空格。
    4. 
    
  4. 请求体选「表单」，添加名为 file 的字段，类型选「文件」，值选「重复项目」。
    5. 
    
  5. 在循环里添加「获取词典值」，从「URL 的内容」读取 message，再用「显示结果」显示它。
    6. 
    
  6. 打开「照片」，选一张截图，点「分享」并向下滚动，选择「存到 PocketMemory」。首次运行时允许连接电脑。收到保存成功提示后，到「记忆库」查看。
    7. 
  

  
Safari 链接和选中的文字

  
另建「链接或文字 → PocketMemory」，打开「在共享表单中显示」，输入类型选 URL 和文本。先用「获取输入中的文本」读取快捷指令输入，再向同一地址发 POST，使用同一 Authorization 标头。请求体选 JSON，添加 text 字段，值选转换后的文本。用「获取词典值」读取并显示返回的 message。

  

  
若分享菜单里没看到快捷指令，检查快捷指令的输入类型与当前分享内容是否匹配。每位用户填写自己的个人密钥。

  
连接不上？

  
确认电脑没休眠、地址没有变化、手机没有使用访客 Wi-Fi。Windows 防火墙如果询问，只允许 Python 访问“专用网络”。当前局域网 HTTP 没有传输加密。
